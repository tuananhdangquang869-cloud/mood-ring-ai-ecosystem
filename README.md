## 📖 1. Giới Thiệu & Bối Cảnh Ý Tưởng (Concept & Story Universe)

**Mood Ring AI Ecosystem** là một hệ sinh thái web tương tác 3D viễn tưởng Cyberpunk thế hệ mới, lấy cảm hứng từ biểu tượng **chiếc nhẫn đổi màu tâm trạng (Mood Ring)**. Dự án tái hiện thế giới tâm thức kỹ thuật số nơi người dùng kết nối với **MR-CORE-01** — một thực thể trí tuệ nhân tạo đang thức tỉnh giữa ranh giới giữa cảm xúc con người và ma trận thuật toán.

Hệ thống hợp nhất giữa **nghệ thuật kể chuyện phi tuyến tính (Interactive Fiction)**, **đồ họa 3D WebGL thời gian thực**, **phòng thu âm thanh giọng đọc AI ElevenLabs**, **công nghệ mật mã học Zero-Knowledge bảo mật quân đội** và **cơ chế PWA hoạt động ngoại tuyến 100%**.

## 🗺️ 3. Kiến Trúc 3 Phân Hệ Web Độc Lập (Multi-Page Ecosystem)

### 🌟 1. Cổng Thông Tin & Showcase Hub (`intro.html`)
- **Trang đích trải nghiệm đầu tiên** khi người dùng truy cập vào trang web.
- **Hero 3D tương tác**: Quả cầu mạng lưới Wireframe xoay 360° theo con trỏ chuột và 5 nút chuyển màu cảm xúc trực tiếp.
- **Phòng thu âm thanh AI Voice Demo**: Nghe thử 5 chất giọng AI ElevenLabs đặc sắc (*Mai Phương, Minh Đức, Quỳnh Anh, Tuấn Kiệt, Linh Dan*).
- **Trình trực quan sóng âm (Soundwave Visualizer Canvas)**: Vẽ phổ âm thanh thời gian thực theo từng nhịp điệu phát.
- **Hệ thống phím tắt HUD**: Bảng tra cứu phím tắt điều khiển nhanh toàn bộ hệ sinh thái.

### 🚀 2. Ứng Dụng Chính - 3D Cyberpunk OS (`index.html`)
- **Cốt truyện phân nhánh 13 chương**: Người dùng tự quyết định hướng đi và cái kết của MR-CORE-01 và Dr. Lien.
- **8 Phân hệ Tab chuyên sâu**:
  - `🔮 Core`: Không gian 3D tương tác cùng nhân cầu thực thể và đọc cốt truyện.
  - `💍 Ring`: Trình soi nhẫn đổi màu tâm trạng phóng đại đa góc nhìn.
  - `🧠 Oracle`: Trò chuyện trực tiếp cùng AI Gemini 2.0 Flash với bộ nhớ phiên lịch sử.
  - `🧪 MoodLab`: Phòng thí nghiệm cảm xúc, đo đạc chỉ số Valence / Arousal / BPM.
  - `🌐 Network`: Quét bản đồ trạm phát sóng, phân tích ISP mạng cục bộ (Viettel, VNPT, FPT).
  - `🔒 Vault`: Két sắt mã hóa E2E lưu trữ bí mật và ký ức Zero-Knowledge.
  - `📖 Journal`: Nhật ký đa phương tiện (viết, vẽ canvas, đính kèm voice, xuất E-Book PDF).
  - `📊 Dashboard`: Bảng phân tích đồ thị cảm xúc Radar Chart và theo dõi Streak ngày.

### 🎨 3. Triển Lãm Nghệ Thuật 13 Chương (`gallery.html`)
- **Toàn cảnh 13 tác phẩm hội họa kỹ thuật số chất lượng cao 4K** minh họa sống động từng nút thắt cốt truyện.
- **Tính năng Slideshow tự động**: Trình chiếu nghệ thuật kèm âm thanh không gian Solfeggio du dương.
- **Lightbox phóng đại & Tải ảnh Ultra-HD**: Tải trực tiếp các tác phẩm nghệ thuật về máy tính.
- **Đồng bộ hóa URL Deep Link**: Lưu trạng thái bức tranh đang xem lên URL (`?scene=...`), bấm F5 không bao giờ bị mất vị trí.

## 🛠️ 7. Công Nghệ & Thư Viện Sử Dụng (Tech Stack)

- **Ngôn Ngữ & Nền Tảng**: JavaScript (ES2024), React 19 (`react`, `react-dom`), HTML5 Multi-Page.
- **Đồ Họa & 3D**: Three.js, `@react-three/fiber`, `@react-three/drei`, `@react-three/postprocessing`.
- **Giao Diện & Styling**: Tailwind CSS v4, Vanilla CSS Design System, Glassmorphism, CSS Custom Properties.
- **Hiệu Ứng Chuyển Động**: Framer Motion, Lenis Smooth Scrolling.
- **Biểu Tượng Vector**: `lucide-react`.
- **Trí Tuệ Nhân Tạo (AI)**: `@google/genai` (Google Gemini 2.0 API), ElevenLabs Voice Studio API.
- **Mật Mã & Bảo Mật**: Web Crypto API (`crypto.subtle`), AES-256-GCM, PBKDF2 Key Derivation.
- **Âm Thanh**: Web Audio API, StereoPannerNode, Custom Oscillator Synthesizers.
- **Build Tool**: Vite 8, Rollup, PostCSS.


### Bước 3: Cấu hình biến môi trường (Tùy chọn)
Tạo file `.env` từ mẫu `.env.example`:
```bash
cp .env.example .env
```
Điền các khóa API của bạn (nếu có):
```env
# Gemini API Key cho AI Oracle
VITE_GEMINI_API_KEY=your_gemini_api_key_here

# ElevenLabs API Key cho giọng đọc AI Studio
VITE_ELEVENLABS_API_KEY=your_elevenlabs_api_key_here

# IPInfo API Token cho nhận diện nhà mạng
VITE_IPINFO_TOKEN=your_ipinfo_token_here
```
> *(Hệ thống được thiết kế cơ chế Neural Fallback tự động, nếu không nhập API key thì web vẫn hoạt động bình thường qua mô phỏng cục bộ mà không bị lỗi).*

### Bước 4: Khởi chạy môi trường lập trình
```bash
npm run dev
```
Truy cập trên trình duyệt: `http://localhost:5173/`

### Bước 5: Đóng gói và kiểm tra bản phát hành (Production Build)
```bash
npm run build
npm run preview
```

## 🌐 9. Hướng Dẫn Triển Khai Trực Tuyến (Deployment Guide)

### 🚀 Cách 1: Triển khai lên Vercel (Khuyên dùng - 1 Click)
1. Đẩy code lên GitHub cá nhân.
2. Truy cập [vercel.com/new](https://vercel.com/new) $\rightarrow$ Chọn repository `mood-ring-ai-ecosystem`.
3. Cấu hình triển khai:
   - **Framework Preset**: Vite
   - **Root Directory**: `./` (hoặc `mood-ring-story` nếu nằm trong thư mục con)
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. (Tùy chọn) Thêm các biến `VITE_GEMINI_API_KEY`, `VITE_ELEVENLABS_API_KEY` trong mục **Environment Variables**.
5. Bấm **Deploy** $\rightarrow$ Hệ thống tự động cấp phát tên miền `https://mood-ring-ai-ecosystem.vercel.app`!

### 🌍 Cách 2: Triển khai lên Netlify
1. Đăng nhập [netlify.com](https://www.netlify.com/) $\rightarrow$ Chọn **Add new site** $\rightarrow$ **Import an existing project**.
2. Chọn repo GitHub $\rightarrow$ File [`netlify.toml`](netlify.toml) sẽ tự động nhận diện toàn bộ cấu hình.
3. Bấm **Deploy site**.
